# Personal Blog

This repository contains a static personal blog built with HTML, CSS, and multimedia assets.

<img width="1220" height="735" alt="image" src="https://github.com/user-attachments/assets/50983482-3284-4e08-b7a2-65038fdc9a90" />


## Project Structure

- `index.html` - Main blog homepage.
- `articulos.html` - Page displaying published articles.
- `articulo.html` - Article detail page.
- `profile.html` - Personal profile or about page.
- `css/` - Site styles.
  - `main.css`
  - `mediaquery.css`
  - `post.css`
  - `posts.css`
  - `profile.css`
- `assets/` - Multimedia resources and icons.
  - `icons/`
  - `images/`
  - `videos/`

## Usage

1. Clone the repository.
2. Open `index.html` in your browser.
3. Edit or add content in the HTML pages and adjust styles in the `css/` folder.

## Customization

- Modify `index.html` to change the main page.
- Adjust styles in the files under `css/`.
- Add new images or videos in `assets/images/` or `assets/videos/`.

## Notes

- This project is intended as a static blog without a backend server.
- Ideal for publishing simple personal or portfolio content.
